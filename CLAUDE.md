# CLAUDE.md

Fork of the IMMENSE pipeline. Project-level docs are in `kansasii-docs` (index, data flow);
`kansasii-docs/docs/WORKFLOW.md` has the run order. Easy to get wrong:

- **Branch `kansasii`** is the working branch; `master` and the others track upstream.
- **Project scripts** are in `scripts/` (`01..12_*`, `run_downstream.sh`, `submit_patients171_tree.sbatch` at the root); the Nextflow pipeline is
  `main.nf` + `modules/`, run through `run_IMMENSE.sh` (days of CPU, `sbatch`, never the login node).
- `README.md`, authors and funding are inherited from upstream; the project docs are `kansasii-docs/docs/WORKFLOW.md`,
  `kansasii-docs/docs/REPOS.md`, `kansasii-docs/docs/SAMPLES.md` (generated by `scripts/08_*`, do not edit by hand), `kansasii-docs/docs/SPECIES.md`, `kansasii-docs/docs/PROJECTS.md`, `kansasii-docs/docs/GIT.md`.
- `git config core.fileMode false` on this filesystem (see `kansasii-docs/docs/GIT.md`).
- `data/imm/screening_map_link.csv` and `screening_map_results.csv` are built by `02_` and `06_`;
  everything downstream reads them. Rerun them whenever the inputs change.
